TASKS

  Task 3.1 — Create game.ts with 4 functions
    File: libs/game/src/lib/game.ts

    Function 1: getFilteredQuestions(category, difficulty): Question[]
      Filter questions array by both category and difficulty
      Return matching subset

    Function 2: getRandomQuestion(pool: Question[]): Question
      Pick random from pool using Math.random()
      Return one Question object

    Function 3: shuffleQuestion(question: Question): Question
      Create index-tracking pairs (text + isCorrect flag)
      Apply Fisher-Yates shuffle to pairs
      Find new position of false statement
      Return new Question with updated statements and answerIndex
      DO NOT mutate original question object

    Function 4: isCorrectAnswer(selected: number, correct: number): boolean
      Return selected === correct
      (Simple but kept separate for testability)

    See DATA_AND_API.txt Section 4 for full implementations.

  Task 3.2 — Update barrel export
    File: libs/game/src/index.ts
    export * from './lib/game';

  Task 3.3 — Manual verification

    console.log(shuffled.statements[shuffled.answerIndex]);
    // Must print the false statement text (same as q.statements[q.answerIndex])
