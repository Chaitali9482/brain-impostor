================================================================
SECTION 4 — STATE TRANSITIONS
================================================================

ON startGame():
  gameStarted = true
  call loadNextQuestion()

ON loadNextQuestion():
  pool = getFilteredQuestions(selectedCategory, selectedDifficulty)
  available = pool.filter(q => !sessionHistory.includes(q.id))
  IF available.length === 0:
    sessionHistory = []         // pool exhausted — reshuffle
    available = pool
  question = getRandomQuestion(available)
  result = shuffleQuestion(question)
  currentQuestion = question
  shuffledStatements = result.statements
  shuffledAnswerIdx = result.answerIndex
  sessionHistory.push(question.id)
  selectedIndex = null
  isAnswered = false
  isCorrect = null
  showModal = false
  timeLeft = 10
  START timer interval

ON timerTick():
  timeLeft -= 1
  IF timeLeft === 0:
    STOP timer interval
    call evaluateAnswer(null)

ON selectAnswer(index: number):
  IF isAnswered → return (guard — no double select)
  STOP timer interval
  selectedIndex = index
  isAnswered = true
  call evaluateAnswer(index)

ON evaluateAnswer(index: number | null):
  isCorrect = (index !== null && index === shuffledAnswerIdx)
  IF isCorrect:
    score += 10
    streak += 1
    IF score > highScore:
      highScore = score
      localStorage.setItem('brainImpostor_highScore', String(score))
  ELSE:
    streak = 0
  showModal = true

ON nextQuestion():
  showModal = false
  call loadNextQuestion()

ON restart():
  STOP any running timer interval
  selectedCategory   = null
  selectedDifficulty = null
  gameStarted        = false
  currentQuestion    = null
  shuffledStatements = []
  shuffledAnswerIdx  = -1
  selectedIndex      = null
  isAnswered         = false
  isCorrect          = null
  timeLeft           = 10
  score              = 0
  streak             = 0
  sessionHistory     = []
  showModal          = false
  (highScore is NOT reset — reads from localStorage again)


================================================================
SECTION 5 — SHUFFLE ALGORITHM (CRITICAL)
================================================================

Function: shuffleQuestion(question: Question): Question

  Step 1: Pair each statement with its original index
    pairs = statements.map((text, index) => ({
      text,
      isCorrect: index === question.answerIndex
    }))

  Step 2: Fisher-Yates shuffle on pairs array
    for i from pairs.length - 1 down to 1:
      j = random integer 0 to i (inclusive)
      swap pairs[i] and pairs[j]

  Step 3: Extract shuffled statements
    shuffledStatements = pairs.map(p => p.text)

  Step 4: Find new position of false statement
    newAnswerIndex = pairs.findIndex(p => p.isCorrect === true)

  Step 5: Return updated question
    return {
      ...question,
      statements: shuffledStatements,
      answerIndex: newAnswerIndex
    }

WHY THIS MATTERS:
  The original answerIndex (e.g. 1) refers to the pre-shuffle order.
  After shuffle, the false statement moves to a new index (e.g. 3).
  If we don't update answerIndex, the game evaluates the wrong card
  as correct. This function guarantees correct mapping every time.

SECTION 7 — TIMER IMPLEMENTATION PATTERN
================================================================

useEffect(() => {
  if (!gameStarted || isAnswered) return;    // don't run if game not active

  const interval = setInterval(() => {
    setTimeLeft(prev => {
      if (prev <= 1) {
        clearInterval(interval);
        evaluateAnswer(null);               // null = timeout = wrong
        return 0;
      }
      return prev - 1;
    });
  }, 1000);

  return () => clearInterval(interval);     // cleanup on unmount or answer

}, [gameStarted, isAnswered, currentQuestion]);

NOTE: Dependency array includes currentQuestion so timer restarts
when a new question loads.


================================================================
SECTION 8 — LOCALSTORAGE FLOW
================================================================

ON MOUNT (useEffect with empty dependency array []):
  const raw = localStorage.getItem('brainImpostor_highScore')
  highScore = raw ? parseInt(raw, 10) : 0
  setHighScore(highScore)

ON CORRECT ANSWER (inside evaluateAnswer):
  IF score + 10 > highScore:
    newHighScore = score + 10
    setHighScore(newHighScore)
    localStorage.setItem('brainImpostor_highScore', String(newHighScore))

ON RESTART:
  score = 0 (session resets)
  highScore stays — re-read from localStorage on mount or kept in state


================================================================
SECTION 9 — GAME CARD VISUAL STATE LOGIC
================================================================

A GameCard receives props and determines its visual state:

  state = 'default'
    IF isAnswered === false
    → Normal dark card, hover effect active

  state = 'correct'
    IF isAnswered === true AND index === correctIndex
    → Green background regardless of whether player selected it

  state = 'wrong'
    IF isAnswered === true
    AND index === selectedIndex
    AND selectedIndex !== correctIndex
    → Red background (player's wrong pick)

  state = 'disabled'
    IF isAnswered === true
    AND index !== selectedIndex
    AND index !== correctIndex
    → Dimmed / faded, no hover effect

This logic means after every answer:
  - Correct card = always green
  - Player's wrong pick = red
  - Other two cards = dimmed
