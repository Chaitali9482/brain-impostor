SECTION 1 — CORE QUESTION TYPE (LOCKED — DO NOT MODIFY)
================================================================

File: libs/types/src/lib/question.ts

--------------------------------------------------------------
export type Category = "Science" | "Maths" | "GK" | "Food";

export type Difficulty = "easy" | "medium" | "hard";

export type Question = {
  id          : number;
  category    : Category;
  difficulty  : Difficulty;
  statements  : [string, string, string, string];   // tuple — exactly 4
  answerIndex : number;                              // 0 | 1 | 2 | 3
  explanation : string;
};
--------------------------------------------------------------

FIELD REFERENCE TABLE

Field        Type                        Required  Rules
-----------  --------------------------  --------  --------------------------------
id           number                      YES       Unique positive integer globally
category     "Science"|"Maths"|"GK"|    YES       Exact string match required
             "Food"
difficulty   "easy"|"medium"|"hard"      YES       Exact string match required
statements   [string,string,string,      YES       Tuple of exactly 4 strings
             string]
answerIndex  number (0 | 1 | 2 | 3)    YES       Points to false statement
                                                   in pre-shuffle order
explanation  string                      YES       Non-empty, explains why false

WARNING: This schema is LOCKED. Do not add, remove, or rename
any field. Do not change Category or Difficulty union values.

================================================================
SECTION 5 — DATA VALIDATION RULES
================================================================

These rules MUST hold for every question in questions.ts:

RULE-01   statements.length === 4  (exactly 4, no more, no less)
RULE-02   answerIndex >= 0 AND answerIndex <= 3
RULE-03   statements[answerIndex] IS the false statement
RULE-04   explanation.trim().length > 0  (non-empty)
RULE-05   id is unique across the ENTIRE questions array
RULE-06   category is one of: "Science" | "Maths" | "GK" | "Food"
RULE-07   difficulty is one of: "easy" | "medium" | "hard"
RULE-08   No two questions have identical statement arrays
RULE-09   The 3 true statements must be verifiably correct facts
RULE-10   The 1 false statement must have exactly ONE wrong detail


================================================================
SECTION 6 — RUNTIME SHUFFLED SHAPE
================================================================

After shuffleQuestion() runs, components receive this shape.
This is NEVER stored — always derived at runtime each question load.

Example: Original question
  id          : 1
  answerIndex : 3   (statements[3] is false)
  statements  : [
    "The Earth revolves around the Sun.",    // index 0
    "Water boils at 100 degrees at sea level", // index 1
    "The chemical symbol for gold is Au.",   // index 2
    "Sound travels faster than light."       // index 3 ← FALSE
  ]

After shuffle (example result):
  statements  : [
    "The chemical symbol for gold is Au.",   // was 2
    "Sound travels faster than light.",      // was 3 ← FALSE — now at index 1
    "The Earth revolves around the Sun.",    // was 0
    "Water boils at 100 degrees at sea level" // was 1
  ]
  answerIndex : 1   ← UPDATED from 3 to 1 (new position of false statement)

The explanation and all other fields remain unchanged.

================================================================
SECTION 9 — LOCALSTORAGE SCHEMA
================================================================

Only ONE key is ever written to localStorage:

Key                          Type     Description
---------------------------  -------  --------------------------------
brainImpostor_highScore      string   Highest score across all sessions
                             (numeric  stored as String(number),
                              as str)  read back as parseInt(value, 10)

Read pattern:
  const raw = localStorage.getItem('brainImpostor_highScore')
  const highScore = raw ? parseInt(raw, 10) : 0

Write pattern (only when new score beats highScore):
  localStorage.setItem('brainImpostor_highScore', String(newScore))

No other localStorage keys are used. No sessionStorage. No cookies.
